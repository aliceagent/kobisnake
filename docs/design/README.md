# Design documents

| File | Purpose | Authority |
|---|---|---|
| `GDD-KOBI-Snake-Design-and-Reference-Pack.txt` | The owner's complete design, discovery and image-prompt pack, verbatim. | Intent |
| `DESIGN-DECISIONS.md` | Fable's resolution of every open question, plus the rules code needs that the GDD left implicit, plus written stand-ins for the concept images that were not supplied. | Numbers, rules, edge cases |
| `ARCHITECTURE.md` | Toolchain, folder layout, simulation/render/UI/audio contracts, test hooks, budgets. | Where code goes and how it is shaped |
| `UI-STYLEGUIDE.md` | Created in Sprint 11. | UI components |
| `AUDIO-NOTES.md` | Created in Sprint 12. | Track structure, how to edit music |

If two documents disagree, the more specific one wins (DESIGN-DECISIONS over GDD for numbers; ARCHITECTURE over
sprint files for file paths), and the disagreement is filed as an issue for Fable to reconcile.
